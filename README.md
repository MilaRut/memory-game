# Memory Game

Браузерная игра на память: нужно найти 8 пар карточек за минимальное число ходов.

Демо: [https://milarut.github.io/memory-game/](https://milarut.github.io/memory-game/)

## Как играть

1. Стартовое поле 4×4 — на нём 16 карточек (8 уникальных изображений, каждое используется по два раза). Поле сразу готово к игре при загрузке страницы.
2. Откройте поочередно две карточки. Если изображения совпадают, карточки остаются открытыми, иначе обе закрываются через 1 секунду.
3. Один ход — это одна пара открытых карточек, независимо от совпадения.
4. Когда найдены все пары, показывается окно победы с числом ходов. Результат сохраняется в таблицу лидеров (хранится в `localStorage`).

**Новая игра** перемешивает карточки и сбрасывает счётчики. **Таблица лидеров** показывает до 10 лучших партий (меньше ходов — выше место, при одинаковом количестве ходов — выше более ранняя запись).

## Стек

- Vanilla JavaScript (ES modules)
- CSS (кастомные свойства, вложенность)
- Vite (сборка)
- GitHub Pages

Сторонние библиотеки и фреймворки не используются согласно ТЗ.
Карточки перемешиваются алгоритмом Фишера-Йетса.
Для модального окна используется нативный `<dialog>` с дополнительной стилизацией.
HTML-элементы интерфейса создаются с помощью кастомной функции-обёртки над document.createElement.
innerHTML и т.п. методы не используются.

## Скрипты для локального запуска

```bash
npm install
npm start        # dev-сервер, порт 3000
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
npm run lint     # ESLint
npm run lint:fix
```

Для GitHub Pages в `vite.config.js` задан `base: '/memory-game/'`. Деплой производится из ветки `memory-game` через GitHub Actions (`.github/workflows/deploy.yml`).

## Структура

```
src/
  script.js          # точка входа
  js/game.js         # логика ходов, проверки пар, победы
  js/render.js       # разметка страницы и модалок
  js/leaderboard.js  # таблица лидеров
  js/utils.js        # DOM-хелперы и shuffle
  css/               # стили
public/              # изображения карточек и логотип
```
